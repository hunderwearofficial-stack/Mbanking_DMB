Syarat dan Ketentuan Layanan Mobile Banking

Hanya versi berstatus PUBLISHED yang ditampilkan ke nasabah (PDF A4 dibuat backend). Alur: buat draf → ubah isi → buat PDF draf & periksa → ajukan → disetujui petugas lain (maker-checker) → terbit. Versi terbit tidak dapat diubah; perubahan selalu menjadi versi baru, dan nasabah diminta menyetujui ulang setelah versi baru berlaku.

Ubah Draf

Isi berupa JSON terstruktur: title, date_note, intro, sections[].heading, sections[].fields[] {label, value}, sections[].blocks[] {text, items[]}, consent_heading, consent_instruction, consent_statements[] (1–5 kotak centang di aplikasi). Penomoran pasal/ayat ditulis di dalam teks. Perubahan substansi wajib disetujui pihak bank.

Notifikasi Push

Notifikasi ke HP nasabah melalui Firebase Cloud Messaging. Notifikasi dari petugas harus disetujui petugas lain sebelum dikirim. Status "Diterima FCM" berarti Firebase menerima pesan untuk diantar — bukan bukti pesan tampil di HP; "Dibuka" tercatat hanya bila nasabah mengetuk notifikasi.
